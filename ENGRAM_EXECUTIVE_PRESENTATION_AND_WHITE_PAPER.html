Research Dossier & System Architecture Whitepaper

Engram: Autonomous Code Review Agent

An AI engineering agent with persistent team memory, AST-validated self-healing multi-agent pipelines, and autonomous GitHub repository analysis.

1. Executive Summary & Value Proposition

In modern software engineering teams, code review consumes up to 35% of senior engineering velocity. While contemporary AI code reviewers (e.g. GitHub Copilot, static analyzers) provide generic pattern matching, they suffer from chronic amnesia: they evaluate pull requests in isolation, oblivious to past architectural debates, team conventions, and institutional knowledge.

The Engram Paradigm: Engram bridges this gap by marrying LangGraph multi-agent orchestration with Hindsight Cloud persistent semantic memory bank. When an engineer accepts or dismisses a convention, Engram commits the decision into long-term memory, ensuring future reviews cite and enforce team-specific conventions with zero amnesia.

❌ Generic AI Reviewers

  • Zero memory across reviews (stateless prompt loops)
  • Repeats discarded textbook patterns, causing PR friction
  • Produces hallucinated syntax and broken diffs
  • Limited to manual code snippet pasting

✅ Engram Agent

  • Persistent episodic & semantic memory in Hindsight Cloud
  • Cites exact past decisions ("Team Convention PR #12")
  • Cyclical AST validation with self-healing retries
  • Autonomous in-memory GitHub repository streaming

2. System Architecture & Multi-Agent Pipeline

Engram orchestrates code auditing using a cyclical directed graph built on LangGraph (StateGraph). Unlike brittle linear prompt chains, Engram enforces strict AST parsing validation and security gates before assembling the final verdict.

Agent Role Pipeline Phase Key Responsibility
Recall Agent recall Embeds code symbols and stack to query Hindsight Cloud for active team conventions.
Analysis Agent analysis Audits code across bugs, performance, security, and team convention alignment.
Fix Agent fix Synthesizes drop-in replacement code and clean unified diffs (diff -u).
Validation Agent validate Executes deterministic AST parsing. If syntax fails, loops back to Fix Agent (max 2 retries).
Security Agent security Evaluates OWASP Top 10, CWE vectors, hardcoded secrets, and injection vectors.
Final Review Agent final_review Combines verdicts, maps Hindsight citations, severity levels, and timeline telemetry.

3. Autonomous GitHub Repository Ingestion Engine

Engram reviews public repositories end-to-end without requiring local git CLI dependencies, Docker daemon, or arbitrary code execution:

In-Memory Tarball Streaming Zip-Slip Traversal Mitigation Deterministic Manifest Profiler Layer-Diverse 5-File Priority 
1. User provides URL: https://github.com/pallets/flask
2. Ingestion: HTTP tarball stream via GitHub Codeload directly into memory.
3. Safe Extraction: Strict traversal checks + filtering (.git, node_modules, binaries, >100KB).
4. Profiling: Manifest inspection (pyproject.toml, package.json) detects stack & architecture.
5. Prioritization: Scores & samples top 5 core files (Entrypoint, Router, Service, DB Layer).
6. Execution: Runs LangGraph pipeline + Hindsight memory recall on each architectural file.
7. Synthesis: Compiles repository blueprint, multi-file diff inspector, and timeline.
